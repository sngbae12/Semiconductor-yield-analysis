# 모델 비교 — 준비 완료, 실제 데이터 실험 미실행

기존 프로젝트 기준 커밋: `6d41e85`. 기존 `secom_analysis.py`, 노트북과 `results/`는 변경하지 않았습니다. 작업 브랜치는 `improve/secom-model-comparison`입니다.

## 기존 분석 검토

- 원본 데이터에서 939/314/314 계층화 분할 후 학습 fold 안에서 결측률 필터, 중앙값 대체, 분산 필터, 표준화, SMOTE, XGBoost를 학습합니다. 직접적인 전처리 누출은 방지되어 있습니다.
- 불량 학습 표본은 62건뿐입니다. 기존 27개 조합의 최고 CV AP 0.2446은 탐색 후 최고 점수이며, 독립적인 성능 추정치가 아닙니다.
- 기존 테스트 AP 0.1270, 기본 임계값 F1 0.1905, 조정 F1 0.1695는 과거 결과입니다. 새 실험 결과로 재사용하지 않습니다.
- 기존 테스트를 추가 튜닝에 사용하지 않습니다. 기존 검증 데이터도 이미 열람된 이력이 있으므로 새 독립 평가라고 부르지 않습니다.

## 실행

```bash
source .venv/bin/activate
python -m pip install -r requirements-experiments.txt
OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 MKL_NUM_THREADS=1 \
  python -m experiments.compare_models --jobs 2 --output-dir experiments/run-001
python -m unittest discover -s tests -v
```

공식 데이터는 `https://archive.ics.uci.edu/static/public/179/secom.zip`에서 받으며 기존 고정 SHA-256과 CRC 및 스키마 검증을 그대로 사용합니다. 현재 실행 환경은 해당 도메인에 프록시 403을 반환합니다. 환경 설정의 도메인 허용을 적용해야 실제 실험을 시작할 수 있습니다. 모의 데이터로 성능을 대체하거나 체크섬 검증을 생략하지 않습니다.

## 사전에 고정한 비교 절차

1. 기존 seed=42 학습 939건만 모델 탐색에 사용합니다. 테스트 314건은 평가하지 않습니다. 분할 행 번호를 기록합니다.
2. 다섯 모델 각각 24개 설정, 동일한 3-fold AP 탐색을 수행합니다. 모델별로 무보정/학습 fold 기반 balanced 가중치/SMOTE를 각각 8개씩 비교합니다. SMOTE와 가중치를 중복 적용하지 않습니다.
3. 결측률 20/40%, 평균/중앙값 대체, 분산 필터, ANOVA 25/50/100% 변수 선택과 모델별 하이퍼파라미터를 탐색합니다. 모든 변환과 재표본화는 학습 fold 안에서만 수행됩니다. 후보 표는 `candidates()`로 재현합니다. 탐색은 제한된 예산의 비교이며 전역 최적 성능을 보장하지 않습니다.
4. 동일한 외부 3-fold에서 내부 탐색을 반복하는 중첩 CV를 수행합니다. 외부 fold의 라벨은 내부 모델·임계값 선택에 사용하지 않습니다. 외부 fold 임계값은 내부 OOF 확률의 F1으로 결정합니다. 내부 OOF는 하이퍼파라미터 선택 후 생성되므로 그 자체의 성능은 독립 추정치가 아닙니다.
5. 외부 평균 AP가 최대인 모델 계열을 **검증 데이터 확인 전에** 고정합니다. 학습 전체에서 재탐색·학습한 각 모델의 검증 지표도 표로 기록하지만, 이 표로 계열을 다시 선택하지 않습니다.
6. 선택한 모델의 검증 F1 최대 임계값을 사용합니다. 동률이면 높은 임계값으로 오탐을 줄입니다. 가능한 모든 임계값의 F1·Recall·Precision·오탐률·오탐 수를 저장해 tradeoff를 공개합니다. 업무 비용 정보 없이 임의의 오탐 비용을 가정하지 않습니다.
7. 중첩 CV의 AP 평균·표준편차와 Accuracy/Precision/Recall/F1/FPR 평균을 저장합니다. 다섯 계열 중 최선을 고르는 과정의 선택 편향은 남습니다. 임계값을 선택한 검증 성능도 낙관적이므로 독립 평가 성능으로 보고하지 않습니다.

모델당 중첩 CV 216회 + 전체 학습 탐색 72회 + 내부 OOF 9회 + refit 4회, 총 약 1,505회 fit입니다. 작업자 2개, 각 모델 내부 스레드 1개로 자원을 제한합니다. 완료 후 `training_comparison.csv`, `validation_comparison.csv`, 전체 탐색 결과, 검증 예측, 임계값별 tradeoff, `selected_model.joblib`, `report.json`이 생성됩니다. 출력 폴더가 이미 존재하면 덮어쓰지 않고 실패합니다.

**현재 결과:** 실제 데이터 접근이 막혀 비교표·최종 모델·개선 여부는 아직 없습니다. 합성 데이터 테스트는 실험 코드 연결만 검증하며 예측 성능의 근거가 아닙니다. 최종 실행 코드/README/의존성의 단일 모델 정리는 실제 비교 완료 후에만 진행합니다.
